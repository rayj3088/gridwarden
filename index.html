What this can't tell you
  • Headroom is a regional, first-order estimate from one study. It is not an interconnection study. Only a utility or grid operator can say whether a specific project can connect.
  • State colors use each state's main grid region. Real grid boundaries cut across state lines.
  • "Campuses that fit" is simple arithmetic (headroom divided by campus size), not a forecast of what will be built.
  • The efficiency setting is a what-if. The 80% preset is a design target, not a measured result.
  • Flexible service is not verified here. Utilities decide what they will count.
  • Tracked construction only covers markets with published figures, so real queues are longer.
  • Power trade compares what a state generates with what its customers buy. Part of any gap is normal line losses and plants' own use (about 8% nationally). Partners are suggestions from these numbers, not existing agreements.
  • Impact figures assume the campus runs at full size all year, so they are an upper bound. Cost uses the state's average retail price; very large customers usually pay less. Water uses US averages, not local cooling designs.
  • Land, noise, jobs and local taxes are not part of these numbers. Risk scores appear only if you load them, and demo values are random.

Data: Duke Nicholas Institute, Rethinking Load Growth (Feb 2025); CBRE North America Data Center Trends (H2 2025, Q1 2026, H1 2026). Headroom is a system-level, first-order estimate, not a study of any single interconnection point. State shading uses each state's main grid region and is approximate. Values for 0.25% and 1% are scaled from national totals.
